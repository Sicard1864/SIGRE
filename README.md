# SIGRE — Système Informatique de Gestion de Révisions Espacées

Application web d'apprentissage par répétition espacée (SM-2/FSRS), classement Elo par tags et gamification.
 Gratuite, open-source (GPL-3.0) et communautaire.

## Stack
- **Backend** : Rust (Axum + SQLx) — `back/`
- **Frontend** : React + TypeScript (Vite) — `front/`
- **Base de données** : PostgreSQL 

## Documentation
Toute la documentation projet est dans [`doc/`](doc/) : architecture, modèle de domaine, conventions de style (Rust, React, SQL, API), navigation et workflow git.
